# Digital Nurture 5.0 Java FSE
## Deep Skilling (Week 3)

### Skills
- Spring Boot 3
- RESTful Web Services
- Spring Data JPA
- Maven Project Management
- Layered Architecture
- Exception Handling

### Technologies Used
- Java
- IntelliJ IDEA / Eclipse IDE
- Spring Boot 3
- Spring Framework
- Spring Data JPA
- Maven
- MySQL
- Postman

### Objective
To learn how to build RESTful web applications using Spring Boot, manage dependencies with Maven, perform database operations using Spring Data JPA, and follow a layered architecture for developing enterprise applications.

### How to Run
- Clone or download the repository.
- Open the project in IntelliJ IDEA or Eclipse.
- Wait for Maven to download all required dependencies.
- Configure the database in `application.properties` (if required).
- Build the project.
- Run the Spring Boot main application class.
- Open Postman or a web browser to test the REST API endpoints.

### Learning Outcomes
- Developed RESTful APIs using Spring Boot.
- Implemented CRUD operations with Spring Data JPA.
- Understood layered architecture.
- Managed project dependencies using Maven.
- Tested APIs using Postman.
